## 三、各文档核心内容速览

### 01 项目分析报告

- **行业分析**：社区超市 11 条业态特征（C-01～C-11）如何推导出功能取舍
- **痛点分析**：管理需求真实但用不动 ERP、数据沉淀为"死账"、人员流动快
- **可行性**：技术 / 经济 / 操作 / 时间四维论证
- **技术选型论证**：为什么 FastAPI（同属 Python 生态，可无缝对接 pandas/mlxtend）、
  为什么 Vue 3 + TS、为什么 MySQL
- **技术难点与对策**：库存一致性、成本核算、促销冲突、重复结算、储值套利等 8 项

### 02 PRD 产品需求文档

- **用户画像**：店长王姐 / 收银员小李 / 库管员老陈 / 采购员小张
- **6 个核心场景**：早高峰收银、顾客临时离场、不停业盘点、临期处理、晚间看数据、促销复盘
- **17 条用户故事**（带优先级）
- **页面地图**：36 个页面的信息架构
- **功能需求**：11 个模块，逐项标注优先级与验收要点
- **关键交互**：收银台布局与交互要点、列表页统一规范、权限配置、促销配置
- **数据指标**：8 个核心业务指标 + 6 个产品健康度埋点建议
- **附录**：角色权限矩阵、单据编号规则、状态机、系统参数清单

### 03 功能需求文档

141 项功能需求，每项含唯一编号（`FRS-XXX-NNN`）、优先级、输入、处理规则、输出、异常码。
可直接派生测试用例，并与接口文档、数据库表形成需求追踪链。

### 04 数据库设计说明书

11 章：概述、设计规范、概念结构（E-R）、逻辑结构、物理结构（索引/容量/归档）、
表结构详细说明、数据完整性、典型业务数据流、性能优化、安全设计、设计总结。
另含 3 张 E-R 图与 1 张逻辑关系图。

### 05 数据设计方案

**核心是第 3 章「十条关键设计决策」**，每条按「业务痛点 → 设计方案 → 权衡取舍 → 实际收益」展开：

1. 库存**流水驱动**（`inv_stock_flow` 为唯一真相源）
2. 单据明细**快照冗余**（历史毛利不被后续进价污染）
3. 会员储值**本金/赠送双轨**（防充值套利）
4. 盘点**冻结账面快照**（不停业盘点）
5. 结算**幂等键**（防重复扣款）
6. 成本核算**移动加权平均**
7. 业务数据**只停用不物理删除**
8. 权限 **RBAC + 数据范围**
9. 分析结果**落表缓存**
10. 热表**索引与归档策略**

另含：数据域划分与流向图、数据与接口的三类供给关系、四条可执行勾稽校验 SQL、
事务边界（T1～T4）、验证结果、设计权衡与局限。

### 06 后端接口文档

5 章：通用约定（认证/响应体/27 个错误码/分页/幂等/RBAC/30 个权限码）、
数据模型（35 个 Schema 逐字段说明）、接口明细（10 个模块 128 个接口）、
附录（接口总索引 + 数据库表映射 + FastAPI 实现建议 + 联调顺序）、文档说明。
