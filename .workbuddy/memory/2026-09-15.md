### 取号算法（已写进提示词，两个坑必须保留）
```sql
INSERT INTO sys_no_seq (seq_key, seq_date, current_val) VALUES (:k, :d, LAST_INSERT_ID(1))
  ON DUPLICATE KEY UPDATE current_val = LAST_INSERT_ID(current_val + 1);
SELECT LAST_INSERT_ID();
```
- 坑 1：表**不能加 AUTO_INCREMENT**，否则"首次插入"路径 `LAST_INSERT_ID()` 返回自增主键值（新键第一次就拿到大数）
  → `sys_no_seq` 用复合主键 `(seq_key, seq_date)`。
- 坑 2：`LAST_INSERT_ID()` 是**连接级**，两条语句必须同一 Session/Connection，否则偶发重号。
